# SOP-03: Wave Picking

Applies to planning, releasing, and executing pick waves.

## Wave planning
1. Group orders into waves by zone and priority (P1 ships first).
2. Pack each wave against the wave capacity of 250 units. A wave over
   capacity is flagged and must be split or re-planned before release.
3. Priority P1 waves are planned before P2 and P3 within the same zone.

## Wave release
1. Every wave release needs a human confirmation gate -- releasing a wave
   commits labor and equipment for the shift.
2. Never release an over-capacity wave without the shift supervisor's
   explicit approval; the labor plan no longer matches the wave.
3. A wave whose units exceed 120% of capacity escalates to T4: stop and
   re-plan, do not release.

## During the wave
1. Pickers work one wave at a time; mixing waves in one cart is forbidden.
2. Short picks are reported immediately so the wave can be re-balanced.
